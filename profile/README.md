# Calculator Comrade

An open-source, cross-platform calculator inspired by classic pocket calculators.

Calculator Comrade is available for web, desktop, and Android.

## Repositories

- [Calculator Comrade](https://github.com/calculator-comrade/calculator-comrade) — applications and website.
- [Calculator Comrade Library](https://github.com/calculator-comrade/calculator-comrade-lib) — C++ calculator engine.
